# Snapemu 支持与帮助

使用 Snapemu 时需要帮助？你可以联系开发者，咨询使用问题、请求技术支持、反馈故障或提出建议。

## 联系支持

### 社区论坛

欢迎访问 [Snapemu GitHub 论坛](https://github.com/gavinliu/Snapemu/discussions)，提问、分享使用经验或提出功能建议。发帖和回复需要 GitHub 账号。

论坛内容公开可见。涉及购买问题或个人信息时，请通过邮件联系我们。

### 邮件支持

电子邮箱：[snapemu@gavinliu.cn](mailto:snapemu@gavinliu.cn?subject=Snapemu%20Support)

点击邮箱链接可打开邮件应用，也可以复制地址到你常用的邮件服务中。支持中文和英文来信，我们会尽快通过邮件回复。

## 反馈时请提供

为了帮助我们了解问题，请尽量提供以下信息：

- 设备型号和操作系统版本。
- Snapemu 版本。
- 你正在进行的操作、实际发生的情况和预期结果。
- 可以重现问题的步骤，以及出现的错误提示。
- 有助于说明问题的截图或短视频，发送前请遮挡个人信息。

如果遇到导入或兼容性问题，请提供游戏平台、文件扩展名和游戏名称。如果遇到购买问题，请说明购买或恢复购买时的情况，以及使用的应用商店。

请勿发送密码、银行卡信息、游戏 ROM 或 BIOS 文件。支持服务不提供游戏文件。

## 联系前可以尝试

- **应用闪退或无响应：** 关闭并重新打开 Snapemu，重启设备，并检查是否有可用的应用更新。如果问题仍然存在，请说明出现问题的时机。
- **游戏无法导入或运行：** 检查是否选择了正确的游戏目录或文件，反馈时注明游戏平台和文件格式。
- **操控无响应：** 检查当前操控设置；如果使用外接手柄，请检查手柄与设备的连接。
- **存档或进度丢失：** 保留现有文件和备份。排查期间请避免卸载应用或删除应用数据，卸载会删除本地数据。
- **专业版购买问题：** 确认应用商店登录的是购买时使用的账号，并尝试在应用中恢复购买。如果仍然失败，请通过邮件提供错误提示。
