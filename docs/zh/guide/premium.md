# 了解专业版

Snapemu 的核心玩法免费可用。专业版在此基础上提供更多个性化选择，让 Snapemu 更贴合你的习惯。

## 计划中的权益

- **控制器换肤**：为虚拟手柄更换不同的皮肤外观。
- **更多封面展示**：在游戏库中使用更丰富的封面展示方式。
- **桌面快捷方式（仅 Android）**：从游戏详情页把游戏添加到系统桌面，一键直达。

## 上线状态与价格

部分权益仍在准备中，尚未全部上线。价格、可用平台与最终方案，以 App 内专业版页面为准。
